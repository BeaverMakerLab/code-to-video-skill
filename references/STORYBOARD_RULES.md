# 分镜设计原则与格式规范 (Storyboard Rules)

在写任何页面代码前，必须先在 `storyboard.json` 中确立整部片子的分镜大纲。

---

## 一、 经典解说短片五段式结构

1. **第 1 页：Hook（3 秒黄金钩子）**：
   - 抛出一个反常识的具体问题或震撼事实。例如：“月薪五千，三十年后凭什么能存到三百万？”
   - 开场必须落在一个具体的具象物体上（如存钱罐），禁止以纯文字卡片开场。
2. **第 2 页：Intuition（核心比喻）**：
   - 全片只能选择 **一个** 核心物理隐喻，贯穿始终（如“雪球”、“天平”、“漏斗”），严禁中途随意更换比喻让观众思维重启。
3. **第 3~5 页：Mechanism（原理与公式拆解）**：
   - 为什么这个结论成立？
   - 采用递进式逻辑链（Cause $\to$ Effect），不要单调罗列要点。
4. **倒数第 2 页：Example & Numbers（具象算例）**：
   - 必须使用资料中真实存在的数字进行推导，让理论落地。
5. **最终页：Close（闭环收敛）**：
   - 画面重新回到开头出现的那个物体或核心比喻上，形成首尾呼应。
   - 结尾台词干脆有力，平实真诚，绝不说教或加空话。

---

## 二、 拍点（Beat）的设计铁律

一个 **Beat（拍点）** 是指屏幕上发生的 **一次有意义的视觉变化**。

```json
{
  "at": "c2:三十年",
  "object": "a desk calendar",
  "action": "flips from year 1 to year 30",
  "camera": "push in",
  "text": "30年"
}
```

1. **`object`（主体）**：必须是真实的名词（如日历、天平、烧杯、芯片），**严禁**使用排版词汇（如 title, card, icon, bullet point, background）。
2. **`action`（动作）**：必须是具象动词（如翻动、下沉、注水、分裂），**严禁**使用泛指动词（如 appear, show, fade in, list）。
3. **`at`（触发时机）**：
   - `c0` 表示当前页第 0 句台词启动。
   - `c1:关键词` 表示当第 1 句台词说到“关键词”的精准瞬间。
4. **频率控制**：每页至少规划 2~4 个 beats，保持每 2~3 秒画面有一次动作与人声互动。
