# 动画设计与代码质量规范 (Design Rules)

## 一、 纯函数原则（绝对不可违反）

渲染引擎基于 $Visual = f(t)$ 进行无头多进程切片渲染，任何时序随机性都会导致多进程合成时画面剧烈跳闪甚至崩溃。

- ❌ **严禁使用**：
  - `Math.random()` $\to$ ✅ 替代方案：`PV.rng(seed)`（固定种子伪随机）
  - `Date.now()`, `performance.now()`
  - `requestAnimationFrame()`, `setTimeout()`, `setInterval()`
  - CSS 动画/过渡（`transition`, `animation`）
- ✅ **正确做法**：
  - 动态状态通过 `P.tick(lt => ...)` 或 `handle.hide(t)` 挂载；
  - 缓动曲线采用 `PV.ease.out`、`PV.K(lt, a, dur, ease)`。

---

## 二、 版面层次与排版规范

1. **三级字号阶梯**：
   - 页面一级标题：`size: 36, weight: 700`
   - 正文与重要指标：`size: 26~28, weight: 400`
   - 辅助标注与单位：`size: 20, color: 'muted'`
2. **安全边距**：
   - 顶部保留给标题：`y: 60 ~ 150`
   - 正文安全区：`x: 140 ~ 1780, y: 180 ~ 880`
   - 底部字幕保护区：$y > 900$ 绝对禁区！
3. **避免要素重叠**：
   - 尽量优先使用自动布局容器：`P.splitLayout({ cols: 2 })` 或卡片包裹 `P.card(...)`。
   - 运行 `check.mjs` 如果出现重叠警告，必须立刻按照建议坐标修正。

---

## 三、 动效美学建议

1. **先声夺人，声画同步**：
   - 翻页瞬间画面切勿一片空白，开场必须已有背景或核心对象。
   - 每个子部件的登场严格跟随解说念到该词的瞬间（`P.cw`），切忌开场就把整张图全贴上让声音去追画面。
2. **运镜稳健克制**：
   - 镜头移动要“快速切入 $\to$ 稳定停驻”（Hold $\to$ Quick Move $\to$ Hold）。
   - 严禁全片持续缓慢漂移（这会造成视觉疲劳并降低可读性）。
   - 震颤/重击效果（`P.shake` / `P.slam`）全片最多出现 1~2 次作为高潮强调。
